# DA3 ggml port — M6 (nested metric depth) Implementation Plan

> REQUIRED SUB-SKILL: superpowers:subagent-driven-development.

**Goal:** Port DA3NESTED-GIANT-LARGE (metric-scale depth) and produce metric depth + camera matching the reference, e2e-verified. This is the FINAL milestone.

**Architecture (da3.py `NestedDepthAnything3Net`):** two branches —
- `model.da3` = **anyview** = GIANT (vitg/DualDPT/cam_dec) — ALREADY ported in M5 (SwiGLU backbone + DualDPT depth + cam_dec pose + GSDPT). 
- `model.da3_metric` = **metric** = ViT-Large (24-layer MLP backbone — metadata-handled) + **DPT head with a sky head** (`head.scratch.sky_output_conv2.{0,2}`) producing metric depth + sky. No cam/gs on the metric branch.

Forward: `output = da3(x)`; `metric_output = da3_metric(x)`; then (NestedDepthAnything3Net):
1. `metric_output.depth = apply_metric_scaling(metric_output.depth, output.intrinsics)` (scale by focal — READ alignment.py).
2. `_apply_depth_alignment`: non_sky_mask = compute_sky_mask(metric.sky, 0.3); median_conf = quantile(output.depth_conf[non_sky], 0.5); align_mask = compute_alignment_mask(output.depth_conf, non_sky, output.depth, metric.depth, median_conf); `scale = least_squares_scale_scalar(metric.depth[align_mask], output.depth[align_mask])` (s=sum(a*b)/sum(b*b)); `output.depth *= scale`; `output.extrinsics[:,:,:3,3] *= scale`; is_metric=1; scale_factor=scale.
3. `_handle_sky_regions`: set sky regions of output.depth to a max (quantile 0.99, capped 200).

**The new pieces (vs M5):** (a) ViT-L metric backbone — reuses the metadata-driven backbone (24 layers, MLP, embed 1024); (b) DPT single-head + **sky head** (the DualDPT main path you have, minus aux, plus a parallel sky_output_conv2 → 1ch sky, sky_activation; note DPT applies output_conv1 in _forward_impl AFTER _fuse, and norm_type may differ — READ dpt.py DPT vs your DualDPT impl and reconcile); (c) the nested alignment host math.
